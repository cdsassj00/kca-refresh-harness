# 독립 프로그램 설정 (받는 사람 체크리스트)

이 프로그램은 **Claude Code 가 필요 없습니다.** Python 과 OpenRouter API 키 하나면 브라우저에서 보고서를 접수하고 3단계를 돌려 신구 대조표를 받습니다. 순서대로 하면 15분 안에 첫 화면이 뜹니다. 1~4는 처음 한 번, 5~8은 보고서마다.

| # | 할 일 | 어디서 | 확인 |
|---|---|---|---|
| 1 | Python 설치 | https://www.python.org/downloads/ | `python --version` → 3.11 이상 |
| 2 | 프로그램 실행 | `app\run_app.bat` 더블클릭 | 브라우저에 대시보드가 뜸 |
| 3 | OpenRouter 키 입력·연결 확인 | 브라우저 [설정] 화면 | "연결 확인" 이 OK |
| 4 | 모델 선택 | [설정] 화면 | 목록에서 고르고 저장 |
| 5 | 샘플 R01 열어보기 | [대시보드] → R01 | 대조표 16행이 보임 |
| 6 | 내 보고서 접수 | [접수] 화면 | 쪽수·글자 수가 표시됨 |
| 7 | 실행 | [실행] 화면 | 단계 진행 표시가 끝까지 감 |
| 8 | 결과 보기 | [결론 대조표]·[산출물] | 판정 배지와 보고서 HTML |

## 1. Python 설치 (처음 한 번)
- [ ] Python **3.11 이상**. 설치 화면에서 **"Add python.exe to PATH"** 를 반드시 체크.
- [ ] 명령창(`Win+R` → `cmd`)에서 `python --version` 이 3.11 이상.
- 이미 루트 `setup.bat` 로 하네스를 설치했어도 이 단계는 같습니다. 가상환경은 따로(`app/.venv`) 만들어집니다.

## 2. 실행 (처음 한 번은 1~2분)
- [ ] `app` 폴더의 **`run_app.bat`** 을 더블클릭. macOS·Linux 는 터미널에서 `bash app/run_app.sh`.
- [ ] 하는 일: 가상환경 생성 → 패키지 설치 → `.env` 준비 → 서버 시작 → 브라우저가 `http://127.0.0.1:8765` 를 엽니다.
- [ ] 검은 창은 서버입니다. **닫으면 프로그램이 꺼집니다.** 끝낼 때 `Ctrl+C` 또는 창 닫기.
- 브라우저가 자동으로 안 열리면 주소창에 `http://127.0.0.1:8765` 를 직접 입력.
- 이 PC 안에서만 접속됩니다(127.0.0.1). 다른 PC 에서 열리지 않는 것이 정상입니다.

## 3. OpenRouter 키 입력·연결 확인
- [ ] 키 발급: https://openrouter.ai 가입 → 오른쪽 위 계정 → **Keys** → **Create Key** → 이름 입력 → **Credit limit(월 한도)** 설정 → 생성된 `sk-or-…` 복사. 자세한 절차는 [../docs/api_keys_guide.md](../docs/api_keys_guide.md) 0절.
- [ ] 결제: OpenRouter 는 선불 크레딧입니다. **Credits** 메뉴에서 소액(예: 10달러)부터 충전.
- [ ] 브라우저 **[설정]** 화면 → `OPENROUTER_API_KEY` 칸에 붙여 넣기 → **저장** → **연결 확인**. `OK` 와 모델 이름이 나오면 됩니다.
- 키는 `app/.env` 에 저장되고 화면에는 앞뒤 몇 글자만 보입니다. 메모장으로 직접 써도 됩니다(`OPENROUTER_API_KEY=sk-or-…`).
- 실패하면: 키를 다시 복사(앞뒤 공백 제거), 크레딧 잔액 확인, 사내 프록시라면 `openrouter.ai` 허용.

## 4. 모델 선택
- [ ] [설정] 화면의 **모델** 목록(OpenRouter 가 제공하는 전체 목록, 검색 가능)에서 고르고 **저장**. 선택은 `app/settings.json` 에 남습니다.
- 처음에는 **성능 좋은 모델 하나**로 시작합니다. 결론 사슬 복원·판정은 긴 문서를 읽고 JSON 을 정확히 내야 해서 값싼 모델이면 형식 오류로 재요청이 늘어납니다.
- **저가 모델(model_cheap)** 은 분류·브리프 같은 가벼운 단계에만 쓰입니다. 비워 두면 기본 모델을 씁니다.
- 검색 공급자는 `auto` 로 두면 됩니다. 검색 키가 하나도 없으면 OpenRouter 의 웹 플러그인(`openrouter_online`)으로 검색합니다. Tavily 나 Exa 키를 넣으면 검색 품질과 속도가 올라갑니다(발급: api_keys_guide 0절).

## 5. 샘플 R01 열어보기
- [ ] [대시보드]에서 **R01**(5G 시장전망 보고서, 2023) 카드를 클릭. 이미 결과가 들어 있어 실행 없이 볼 수 있습니다.
- [ ] [결론 대조표]: 결론 16행. 행을 누르면 원 결론 / 추적 재도출 / 블라인드 3열과 근거 링크가 펼쳐집니다.
- [ ] [산출물]: 현행화 보고서 HTML, 대조표 HTML, 브리프, 검토 노트.
- [ ] [영향 지도]: 사건 → 전제 → 결론 → 제언 연결 그림.

## 6. 내 보고서 접수
- [ ] [접수] 화면에 파일을 끌어다 놓기. **PDF · HWPX · DOCX · TXT** 는 바로 됩니다. **HWP**(구 한글)는 `pyhwp` 를 설치했을 때만 됩니다. 안 되면 한글에서 "다른 이름으로 저장 → HWPX 또는 PDF" 후 넣으세요.
- [ ] ID 는 비우면 다음 번호(`R08`…)가 자동으로 붙습니다. 제목·발간연월(YYYY-MM)을 넣으면 현황판에 그대로 실립니다.
- [ ] 업로드 뒤 **쪽수·글자 수**를 확인. "스캔본" 경고가 뜨면 글자가 없는 이미지 PDF 입니다. OCR 을 거친 PDF 로 다시 넣으세요.
- 원문 글자는 `reports/<ID>/00_source/` 에 내 PC 에만 남습니다.

## 7. 실행
- [ ] [실행] 화면에서 보고서 선택 → 층 체크(**L0** 바뀐 것 찾기 · **L1** 숫자 다시 맞춰보기 · **L2** 결론 다시 내보기) → 옵션 확인 → **실행**.
- [ ] 처음에는 **L0 만** 켜고 돌려 비용과 시간을 봅니다. 그다음 L1·L2 를 켜고 다시 실행하면 이미 끝난 단계는 건너뜁니다.
- [ ] 스테퍼로 단계 진행이 보이고, 아래에 로그와 **토큰·비용 누계**가 흐릅니다. 중간에 **취소**하면 다음 단계 경계에서 멈춥니다. 같은 보고서로 다시 실행하면 이어서 합니다.
- 보고서 한 편에 L0~L2 전체는 30분~1시간이 걸립니다(모델·검색 속도에 따라 다름). 창을 닫지 마세요.
- 특정 단계부터 다시 하려면 "강제 재실행 단계"에 그 단계 이름을 고릅니다. 기존 파일은 `.bak.<시각>` 으로 남습니다.

## 8. 결과 보기
- [ ] [결론 대조표]: 판정 7종(동일·강화·부분수정·약화·뒤집힘·신규결론·판정불가) 배지와 다음 조치(유지·부록 갱신·재연구 발주·폐기·추가 조사). 필터로 추려 봅니다.
- [ ] [산출물]: `07_report/report.html`(현행화 보고서), `comparison_table.html`(대조표), `critic_notes.md`(검토 결과, PASS 여야 완료).
- [ ] 파일 위치: `reports/<ID>/`. 공유할 때는 `07_report/` 의 HTML·Markdown 만 보내면 됩니다.
- [ ] 현황판 `registry.csv` 에 성숙도(L0/L1/L2)와 갱신 시각이 적힙니다.

## 비용 안내
| 항목 | 내용 |
|---|---|
| 과금 방식 | **종량제**(토큰 수 × 모델 단가). 구독 없음. OpenRouter 선불 크레딧에서 차감 |
| 어디서 확인 | [실행] 화면의 비용 누계, 실행 요약 `runs/<job_id>.json`, OpenRouter **Activity** 페이지 |
| 한도 걸기 | 키 만들 때 **Credit limit** 을 두면 그 이상은 호출이 거부됩니다. 한 달 예산을 키 한도로 두는 것을 권장 |
| 줄이는 법 | L0 만 실행 · 블라인드 재수행 끄기 · 저가 모델을 `model_cheap` 에 지정 · 검색 결과 수 줄이기 |
| 감 잡기 | 보고서 한 편(100쪽대)에 LLM 호출 수십 회, 입력 토큰 수십만 개 규모. 모델 단가 차이가 커서 한 편에 수백 원에서 수만 원까지 벌어집니다. 첫 실행은 L0 만 돌려 실제 비용을 본 뒤 결정하세요 |

## 데이터가 어디로 가나 (기관 판단 필요)
| 구간 | 무엇이 가나 | 비고 |
|---|---|---|
| 내 PC (`app/`) | 원문 글자, 산출물, 키 | 모두 이 폴더 안에만 저장 |
| → OpenRouter | 원문 글자(단계별 입력), 프롬프트, 검색 결과 | 미국 회사. 계정 설정 **Privacy** 에서 학습·로그 허용 여부를 정할 수 있음 |
| → 모델 제공사 | OpenRouter 가 고른 공급자(OpenAI·Anthropic·Google 등)에 같은 내용 전달 | 공급자별 데이터 정책은 OpenRouter 모델 페이지에 표시 |
| → 검색 공급자 | 보고서 주제가 담긴 **검색어**만 | Tavily·Exa·NAVER 또는 OpenRouter 웹 플러그인 |
| → 근거 소스 API | 논문·통계·법령 **검색어**만 | OpenAlex·KOSIS·법제처 등 |

- 비공개·대외비 보고서를 넣기 전에 **기관의 정보보안 규정**(외부 AI 서비스 전송 가능 여부, 학습 미사용 조건)을 확인하세요. 판단 전에는 공개 보고서만 권합니다.
- OpenRouter 를 거치지 않고 **특정 제공사와 직접 계약**한 API 를 쓰려면 [설정]의 `LLM_BASE_URL` 을 그 제공사의 OpenAI 호환 주소로 바꾸고 `OPENROUTER_API_KEY` 자리에 그 제공사 키를 넣습니다(예: 사내 vLLM·Ollama `http://localhost:11434/v1`). 모델 목록·비용 표시는 공급자에 따라 비어 있을 수 있습니다.
- 키 값은 `app/.env` 에만 있고 로그·산출물에 기록되지 않습니다. `.env`·`settings.json`·`.venv` 는 git 에 올라가지 않습니다.

## 문제 해결
| 증상 | 조치 |
|---|---|
| 검은 창이 바로 닫힘 | 명령창을 열어 `app` 폴더에서 `run_app.bat` 를 실행하면 메시지가 남습니다. 대개 Python 미설치 또는 PATH 미체크 |
| "address already in use" | 이미 서버가 떠 있습니다. 먼저 뜬 창을 닫거나 브라우저에서 `http://127.0.0.1:8765` 를 그냥 여세요 |
| 연결 확인 실패 | 키 재복사, 크레딧 잔액, 프록시. [설정] 아래 **doctor** 표에서 `llm` 행의 메시지를 봅니다 |
| 검색이 안 됨 | doctor 표의 `search` 행 확인. 검색 키가 없으면 `openrouter_online` 으로 자동 전환됩니다 |
| 근거 소스 상태 | [설정] doctor 표, 또는 루트에서 `python scripts\evidence.py doctor` |
| 단계가 "failed" | [실행] 로그의 마지막 오류를 봅니다. 형식 오류가 반복되면 모델을 더 좋은 것으로 바꾸고 그 단계부터 강제 재실행 |
| HWP 가 안 열림 | `pyhwp` 미설치. 한글에서 HWPX 또는 PDF 로 저장해 넣으세요 |
| 자체 점검 | `app` 폴더에서 `python -m pytest tests` (서버·엔진 테스트, 키 없이 동작) |
| 하네스 쪽 점검 | 루트에서 `python -m pytest` (계산기·스키마 테스트) |

로그: `reports/<ID>/logs/app_run.jsonl`(단계별 호출·토큰·비용), 실행 요약 `runs/<job_id>.json`. 키 값은 들어 있지 않으니 그대로 보내 문의해도 됩니다.
