# 리서치 계획: 한국방송통신전파진흥원(KCA) 기존 정책연구 보고서 선정

## 핵심 질문
KCA가 과거에 수행한 정책연구·연구용역 중, "지금 다시 수행하면 결과가 달라질 것인가"라는
관점(AI Deep Research 재검증·재평가 시연)에 적합한 연구보고서 5편을 찾아 PDF로 확보한다.

## 선정 기준
1. 원문 PDF가 공개되어 다운로드 가능할 것 (KCA 홈페이지, PRISM, 알리오, 국회도서관 등)
2. 발간 후 3~7년 경과하여 정책·기술·산업 환경 변화가 뚜렷할 것 (2018~2022년 발간 우선)
3. 보고서에 "전망·예측·정책대안·로드맵"이 포함되어 재검증 대상이 명확할 것
4. 주제 다양성: 전파(주파수), 방송, 통신, 디지털 미디어/콘텐츠, 기관 경영·사업 등 분산

## 하위 주제
- S1. KCA 홈페이지(kca.kr) 연구보고서/정책연구 게시판 목록 파악
- S2. PRISM(정책연구관리시스템) 등록 KCA 발주 연구용역 목록 파악
- S3. 후보 보고서 요약 확인 및 5편 선정, PDF 다운로드

- reports/ : 다운로드한 PDF 5편
- research_kca_reports/selected_reports.md : 최종 선정 근거 요약
