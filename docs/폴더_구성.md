# 폴더 구성 — 공통 핵심 / Claude Code 하네스 / 독립 프로그램

이 저장소의 파일은 세 묶음으로 나뉩니다. **공통 핵심**은 두 실행 방식이 같이 쓰는 원본이고, 나머지 둘은 그것을 돌리는 "실행 방식"입니다. 어느 묶음을 지워도 다른 묶음은 깨지지 않도록 되어 있습니다(단, 공통 핵심은 둘 다에 필요).

| 묶음 | 무엇 | 필요한 것 | 시작 |
|---|---|---|---|
| **공통 핵심** | 규칙·절차서·지식베이스·계산기·서랍·현황판 | Python 3.11 | (직접 실행하지 않음) |
| **Claude Code 하네스** | Claude Code 가 공통 핵심을 스킬·서브에이전트로 실행 | Claude Code 로그인 | `setup.bat` → `/refresh-run R01` |
| **독립 프로그램** | FastAPI 서버 + 브라우저 화면이 공통 핵심을 OpenRouter 로 실행 | OpenRouter 키 | `app\run_app.bat` |

## 2. 파일이 어느 묶음인가

| 파일·폴더 | 묶음 | 하네스가 쓰나 | 독립 프로그램이 쓰나 | 비고 |
|---|---|---|---|---|
| `prompts/*.md` | 공통 핵심 | 스킬·에이전트가 읽음 | `stages.py` 가 파일 전문을 프롬프트로 넣음 | 단일 원본. 복사·수정 금지 |
| `templates/schemas/*.json`, `verdict_rules.yaml`, `taxonomy.yaml` | 공통 핵심 | `scripts/validate.py` | 같은 `validate` 를 import | |
| `templates/*.md` (양식) | 공통 핵심 | L3 설계서·보고서 목차 | 같음 | |
| `kb/events/`, `kb/evidence/`, `kb/domains/` | 공통 핵심 | 선독후기 | `read_core_file` 도구·delta 단계 | `kb/cache/` 는 git 제외 |
| `scripts/*.py` | 공통 핵심 | Bash 로 실행 | Python 으로 import | 계산·렌더는 AI 가 아니라 여기서 |
| `samples/pdf/` | 공통 핵심 | `intake.py` 입력 | 접수 화면에서 업로드 가능 | |
| `reports/<ID>/` | 공통 핵심 | 산출물 저장 | 같은 경로에 저장 | 서로 열어 볼 수 있음 |
| `registry.csv` | 공통 핵심 | `registry.py` | 접수·실행 끝에 갱신 | |
| `runs/` | 공통 핵심 | 실행 기록 | `runs/<job_id>.json`, `runs/uploads/` | git 제외 |
| `tests/`, `pytest.ini`, `requirements.txt` | 공통 핵심 | `python -m pytest` | 동일 + `app/tests` | |
| `CLAUDE.md` | Claude Code 하네스 | 자동 로드 | "규칙" 절만 `engine/system_prompt.md` 로 옮겨 씀 | 원본은 여기 |
| `.claude/skills/`, `.claude/agents/`, `.claude/settings.json` | Claude Code 하네스 | 명령·역할·권한 | 읽지 않음 | prompts 를 감싼 포장 |
| `AGENTS.md` | Claude Code 하네스 | 다른 도구 안내 | 읽지 않음 | |
| `SETUP.md`, `setup.bat`, `setup.sh` | Claude Code 하네스 | 설치 | 읽지 않음 | |
| `.env` (루트) | Claude Code 하네스 | `scripts/evidence.py` 가 읽음 | 읽지 않음 (app/.env 사용) | git 제외 |
| `app/run_app.*`, `app/requirements.txt` | 독립 프로그램 | 읽지 않음 | 실행·설치 | |
| `app/.env`, `app/settings.json`, `app/.venv/` | 독립 프로그램 | 읽지 않음 | 키·모델·패키지 | git 제외 |
| `app/config.py`, `app/engine/`, `app/server/`, `app/ui/`, `app/tests/` | 독립 프로그램 | 읽지 않음 | 본체 | |
| `app/README.md`, `app/SETUP.md`, `app/DESIGN.md` | 독립 프로그램 | – | 문서 | |
| `docs/` | 문서 | – | – | 둘 다 참고 |

## 3. 셋의 관계 한 줄씩

- **공통 핵심이 원본.** 절차·규칙·지식·계산을 고치면 두 실행 방식에 동시에 반영됩니다. 실행 방식 폴더에는 "어떻게 돌리나"만 있습니다.
- **Claude Code 하네스**는 `prompts/` 를 `.claude/skills` 로 감싸고 역할을 `.claude/agents` 로 나눠 Claude Code 가 서브에이전트로 돌립니다. 키는 루트 `.env`.
- **독립 프로그램**은 같은 `prompts/` 를 `engine/stages.py` 가 순서대로 LLM(OpenRouter)에 보내고, 검색·열람 도구 호출을 중계하며, 결과를 같은 `reports/` 에 씁니다. 키는 `app/.env`.
- 두 방식 모두 블라인드 재수행 격리(브리프만 제공, `files_opened` 기록)와 작성자·검토자 분리를 지킵니다.
- 하나만 배포해도 됩니다. 독립 프로그램만 줄 때는 `app/` + 공통 핵심 + `docs/` 를 보내면 되고, `.claude/`·`AGENTS.md`·`setup.bat` 은 빼도 됩니다.
