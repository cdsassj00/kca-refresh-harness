# 현행화 보고서 목차 양식 (report_outline)

> 설계서 9절 기준. `scripts/render_report.py <id>`가 `reports/<id>/07_report/report.md`·`report.html`을 이 순서로 조립한다.
> 모든 수치·문장은 단계별 JSON 산출물에서만 가져온다. 렌더러가 새 수치를 만들지 않는다.
> 입력 파일이 없으면 해당 절은 `(아직 생성되지 않음: 단계 X 실행 필요)`로 표시한다.
> 원 결론 문장(old)은 절대 고치지 않는다.

문서 머리: `# <보고서 제목>` / `보고서 <id> · 발간 <YYYY-MM> · 비교 생성 <날짜> · 성숙도 <L0~L3> · 렌더 <시각> · 입력 <n>/<N>개 확인`

## 1. 결론 재도출 요약
- 입력: `comparison_table.json` (`summary`, `conclusion_rows`). 없으면 `L0/provisional_verdicts.json`의 예상 방향 분포로 대체.
- 판정별 개수 표: 동일 / 강화 / 부분수정 / 약화 / 뒤집힘 / 신규결론 / 판정불가 / 잠정
- 핵심 3건: 뒤집힘 → 신규결론 → 판정불가 → 약화 → 부분수정 순으로 3건. 열 = 결론·판정·현행화(안) 요지·왜 달라졌나(P/E/M + 사유)·등급·상태·다음 조치

## 2. 원 연구 개요와 논증 사슬
- 입력: `01_meta.json`, `02_classification.json`(`research_design`), `03_argument_chains.json`
- 개요 표: 제목·발행·발행/수행기관·원문(쪽수)·도메인·유형 혼합
- 연구질문(RQ) / 방법 목록 / 데이터 목록 / 원 연구가 밝힌 한계 / 표본·범위
- 논증 사슬 요약 줄: 결론 n · 전제 n · 주장 n · 연결 n
- 결론 목록 표: 결론 ID·종류(RQ/F/Fc/R)·쪽(인쇄)·결론 문장(요지)·방법·전제 수·근거 수·재수행 등급(R1~R3)

## 3. 환경변화 브리프
- 입력: `L0/events.json`(+ `L0/environment_delta.md` 참조 안내)
- 요약 줄: 사건 n건 · 도메인별 · 등급별
- 사건 표: 날짜 · 사건 · 영향 지표 · 등급 · 출처(링크, 2건 + "외 n건")

## 4. 결론 대조표
- 입력: `comparison_table.json` `conclusion_rows`
- 행별 열: 결론·위치 | 현행(원 보고서, 원문 요지 그대로) | 현행화(안)·추적 재도출 | 블라인드 재수행 | 판정 | 왜(P/E/M · 사유) | 등급 | 상태 | 다음 조치
- 다음 조치 어휘: 유지 / 부록 갱신 / 재연구 발주 / 폐기 / 추가 조사 (필드 `next_action`, 없으면 "—")

## 5. 근거 재검증 매트릭스
- 입력: `L1/verdicts.json`
- 요약 줄: 항목 n(claim/conclusion) · 판정 분포(적중/유효/수정필요/검증불가)
- 표: 주장 ID · 결론 ID · 수준 · 지표 · 원 값 · 현재 값(기준시점) · 오차 % · 판정 · 사유 · 근거 수·최고등급

## 6. 재수행 시뮬레이션 상세
- 트랙 A 추적 재도출 (`L2/traced/traced_conclusions.json`): 결론별 적용 방법 · 입력 표(값·단위·기준시점·등급·출처) · 재도출 결과 · 원 결론 대비 · 계열 표(연도별) · 계산 메모. 등급은 C(시뮬레이션).
- 트랙 B 블라인드 재수행 (`L2/blind_output/blind_conclusions.json`):
  - **격리 확인 줄(필수)**: `files_opened` 목록과 원문·비교·재도출 산출물 접근 여부. 항목이 없으면 "격리 여부 미확인"으로 적는다.
  - 항목 표: 항목 · 질문 · 블라인드 결론 · 확신 · 등급 · 입력 수 · 대응 결론(비교기 `blind_mapping`)
  - 블라인드 에이전트가 밝힌 유의점(caveats)
- 비교기 규칙·입력 (`comparison_table.json` `l2_compare`)

## 7. 새로운 정책 시사점
- 입력: `comparison_table.json`에서 판정이 신규결론·뒤집힘인 행
- 행별: 시사점(현행화(안) 문장) · 근거·판정 사유 · 근거 목록([등급] 링크) · 연결 전제·사건(upstream)
- 해당 행이 없으면 "해당 없음"

## 8. 부록
- 8.1 본문 대조표 (`body_rows`): 위치 · 현행 · 현행화(안) · 변경유형(유지/수치갱신/서술수정/폐기/신규추가/재수행필요) · 사유 · 등급 · 상태 · 연결 결론
- 8.2 사용한 소스·등급 통계: 모든 산출물의 근거 항목 수 · 고유 URL 수 · 등급 분포 · 호스트별 인용 횟수
- 8.3 미확인 항목: 판정불가·잠정 결론, L1 검증불가 주장, 확신 낮음 블라인드 항목, L0 확인 실패 목록
- 8.4 입력 산출물 존재 여부: 입력 · 경로 · 있음/없음
- (재설문·재실험 설계서는 `templates/survey_redesign.md`·`templates/experiment_plan.md` 양식으로 별도 파일 첨부)

문서 꼬리: 등급 설명(A 1차·공식 / B 2차 / C 추정·시뮬레이션·블라인드 결론) + "새로 만든 수치 없음" 고지
